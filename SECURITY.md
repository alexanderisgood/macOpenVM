# Security policy

macOpenVM is an experimental source-only alpha. There is no supported security
release or guaranteed response time yet. VM isolation, guest integration, storage
ownership and untrusted protocol handling remain security-sensitive work.

Report a suspected vulnerability through
[GitHub private vulnerability reporting](https://github.com/alexanderisgood/macOpenVM/security/advisories/new).
Private reporting is enabled for this repository. If the private form
is unavailable, open an issue asking for a private reporting channel without
including vulnerability details. Maintainer: [alexanderisgood](https://github.com/alexanderisgood).

Include the affected revision, expected behavior, a minimal reproduction and
impact. Use generated inputs where possible. Do not submit credentials, VM disks,
guest files, personal paths or unredacted logs. Coordinate disclosure with the
maintainer before making sensitive details public.

GitHub documents the process in
[Privately reporting a security vulnerability](https://docs.github.com/en/code-security/how-tos/report-and-fix-vulnerabilities/report-privately).
