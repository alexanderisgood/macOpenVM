# Design and validation notes

The ADRs describe design decisions and historical experiments, rather than a
support guarantee. Private machine logs, handovers and VM-specific evidence
were omitted from this source preview. See ../FEATURE_MATRIX.md for current
public scope and release.md for validation limits.

Fixed private-evaluation paths and VM identifiers in the lab code and tests
use inert example values in this snapshot. Existing exact-match, ownership
and hash checks are preserved; excluded runtime assets are not discovered or
automatically downloaded.
